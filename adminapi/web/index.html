ONBOARDING POLICY

Enrollment requirements

Required steps must be completed. Optional steps can be skipped. Disabled steps are omitted from onboarding; existing credentials remain usable.

Hiding password entry disables password enrollment. Enabling password enrollment selects after email verification by default.

Password policy

Rules apply to new passwords. ASCII letters, digits and printable punctuation only; no whitespace. Rules remain saved when password enrollment is disabled.

Identity document capture

New capture sessions use these settings. Existing captures retain the disclosure the user accepted.

Document type: ID card (including driver’s licenses and state or federal IDs).

One disclosure per language. Country of origin is collected after scanning. English is the fallback when a translation is unavailable.
